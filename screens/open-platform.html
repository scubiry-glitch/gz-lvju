新居住开放平台

面向商家（运营商 / 服务商）与平台运营方的统一入口。开放能力按业务线分开提供：房源（旅居 / 长租 / 惠居）、通用本地生活（保洁 / 维修 / 保姆 / 养老…）、搬家（垂类）。所有开放接口统一使用 HMAC-SHA256 商家签名鉴权，一套凭证按业务线授权，不接受其他鉴权方式。

3 条业务线分开接入 18 个开放接口 仅 HMAC-SHA256 一种鉴权 在线签名调试台 回归脚本开箱即用

1 三步接入

1领取凭证平台为商家配置接入密钥，线下下发 vendor_id + hmac_key；密钥等同密码，只放服务端。
2签名调通读签名算法，用在线调试台或回归脚本调通所属业务线的查询接口。
3创建并上架房源走 projects/create（草稿）→ 补价与户型 → projects/status 上架；本地生活 / 搬家商品走 products/create。
环境：联调/演示 https://sytest.meizu.life（本页同源，接口走相对路径 /api/juzhu/*）；生产 Base 以平台接入单下发的域名为准，接口与签名不变。

4 开放接口速查（均为 HMAC 签名 POST）

4.1 房源业务线（/api/juzhu/housing/vendor/*）

接口说明
POST /housing/vendor/projects/list本商家房源列表（channel / status / city_id / keyword 过滤）
POST /housing/vendor/projects/detail房源详情 + 户型明细
POST /housing/vendor/projects/create创建房源（默认草稿，可带户型）
POST /housing/vendor/projects/update增量更新（价格 / 标签 / 保险 / 最短连住）
POST /housing/vendor/projects/status上架 online / 下架 offline / 草稿 draft
POST /housing/vendor/units/create · units/update户型新增与调价 / 夜价
POST /housing/vendor/stay-calendar/set逐晚房态：关房 / 开房 / 夜价覆盖（已订晚不可改）

4.2 通用本地生活业务线（/api/juzhu/jiazheng/vendor/*）

接口说明
POST /api/juzhu/jiazheng/vendor/products/list|detail|create|update|status|delete商家商品（服务）管理；金额单位「分」
POST /api/juzhu/jiazheng/vendor/cities|categories|skus/list开放城市 / 类目 / 平台标准品查询
POST /api/juzhu/callback订单状态回调（商家 → 平台，含服务者信息）

4.3 搬家业务线

搬家不自建接口，复用 4.2 的全部开放接口（类目 moving），增量部分是业务约定：引用平台搬家标准品（6 个 SPU）、商家可售商品规则、订单状态机与联调验收清单，见 搬家服务商接入指引。

完整入参出参见对应文档：房源 v2.0 · 本地生活 v1.0（商家接口章节） · 搬家指引。鉴权统一为 HMAC-SHA256，开放接口不接受其他鉴权方式。

5 常见问题

签名失败、上架不生效、房态改不动、密钥遗失……高频问题与排查路径整理在 开放平台 FAQ。

找不到答案？联系平台接入群，报 vendor_id + 接口路径 + timestamp + 返回的 message（不要发密钥）。
