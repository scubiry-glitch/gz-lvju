1 · 入驻开通（账号 · 资质 · 密钥）

1.1 三步接入（API 商家）

  1. 领取凭证：平台为商家配置接入密钥，线下下发 vendor_id + hmac_key；密钥等同密码，只放服务端。自助入驻申请（原型）→
  2. 签名联通：用在线调试台或回归脚本调通所属业务线的查询接口（HMAC-SHA256）。
  3. 创建并上架：projects/create 建稿（默认不进 C 端，补户型与价格）→ 平台核验 → projects/status 上架。

1.2 入驻资料清单（资质上传）

资料要求必交
营业执照在有效期内、经营范围含住宿 / 租赁经营必交
经营许可（旅馆业特种行业许可 / 卫生许可）按属地要求提供；民宿须有必交
法人身份证与营业执照法人一致必交
消防 / 安全凭证按属地要求按需
结算账户对公账户，户名与营业执照一致必交
保证金按房源规模分档（档位待定）必缴

审核时限：资料齐全后 T+2 出结果；驳回有留痕理由与申诉通道。

红线：密钥不得写进前端 / App；发现泄露立即联系平台重签（重签吊销旧密钥）。

2 · 房源上架规范

2.1 频道归属

房源创建时须指定频道：rental（租赁住宿 = 长租 + 旅居，监管同口径）或 minsu（惠居民宿）。旅居视图只展示带「旅居」标签的 rental 房源；频道与标签由平台在核验时校准。

2.2 信息与照片

  • 位置 / 房型 / 面积 / 价格真实准确；一房一档。
  • 照片 ≥ 8 张，实拍、禁盗图禁过度修图（AI 图像查重会拦截「照骗」）。
  • 按彩贝 5 维填写设施自查表（环境景观 / 服务品质 / 设施配套 / 交通区位 / 特色体验）。
  • 周边玩法由平台运营配置（景区 / 商圈 / 美食 / 咖啡），商家可申报。

2.3 房态 · 连住 · 按晚预订

  • 逐晚房态：open / blocked / booked；客户订单占用的夜晚自动锁定，任何接口不可改已订晚。
  • 最短连住：rental 默认 15 晚、minsu 默认 1 晚，可在 ext 按项目覆盖（1–365）。
  • 按晚预订开关（stay_bookable）：缺省关闭 = 仅 400 电话咨询；开通后「无行 = 默认可订」才对外生效。逐晚价 / 关房在商家房态日历或 API 配置。
  • 上下架：draft / online / offline；C 端只出 online，上下架最迟 15 秒生效。

3 · 订单履约与客诉配合

  • 接单确认：平台通过 Webhook 推送待确认订单，商家须在承诺时限内 查单 / 确认 / 拒单；拒单需留理由。
  • 入住 / 离店：电子凭证核验；房间与照片不符属重大客诉源，请在上架前自查。
  • 取消 / 退款：按平台政策分档执行（免费取消截止日待定）；购取消险客户享宽松退改，商家结算同步扣减。
  • 客诉配合：客诉经 星云客服 400 进线建工单 → 平台分派商家核实 → 商家 48 小时内反馈处理结果；整改情况进商家考核与评级。

4 · 结算与对账

  • 资金存管：客户房款经银行存管（贵州银行），平台不碰资金池。
  • 结算周期：入住确认后 T+7 结算至商家结算账户。
  • 佣金：暂定 10% 平台费用为基准，折扣按商务约定（差别化费率的配置化能力在建）。
  • 对账：平台对账日清；商家请按月核对结算单，差异 3 日内提出。
  • 发票：一期预留、三期完善；平台侧开具平台费发票。

5 · 评级（旅居彩贝）与品控抽查

维度权重要点
环境景观22 分自然 / 在地文化 / 信息真实度
服务品质22 分管家响应、安心保障、安维与保修
设施配套24 分客房硬件 / 智能设备 / 基础设施 / 包裹入住条件
交通区位14 分距景区距离 / 交通接驳 / 停车
特色体验18 分在地文化主题 / 民俗研学 / 康养 / 景区联动
  • 评级从 一彩贝 到 五彩贝；上架预打分 → 存续期动态调级。
  • 品控抽查：平台客源管家存续期抽查（房源与实拍一致、服务履约），结果进评级与商家考核。
  • 彩贝等级越高可享受的流量分发与差别化费率激励越多（能力在建）。

7 · API 对接指引

  • 路径前缀 /api/juzhu/housing/vendor/*，全部 POST、JSON；HMAC-SHA256 签名，与家政开放接口同一套密钥体系。
  • 14 个接口：房源创建 / 更新 / 上下架 / 户型 / 逐晚房态 / 保险标识，订单履约（查单 / 确认 / 拒单）与 Webhook 事件。
  • 数据归属隔离：按 owner_vendor_id 隔离，只能命中自己的房源。
  • 联调环境：https://sytest.meizu.life；生产 Base 以平台接入单下发域名为准。

8 · 常见问题与入口汇总

  • 上架后 C 端搜不到？→ 检查 status 是否 online、按晚预订是否开通、频道与「旅居」标签是否正确（15 秒缓存）。
  • 想改价但已订晚？→ 已订晚被订单锁定，只能改未订晚（逐晚房态）。
  • 退款怎么算？→ 平台政策分档 + 商家在结算侧同步扣减；有争议走客诉工单仲裁。
