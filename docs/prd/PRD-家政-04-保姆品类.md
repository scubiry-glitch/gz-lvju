> 版本：v1.0 | 日期：2026-07-09 | 品类 ID：`nanny` | 优先级：P0

---

## 1. 品类概述

| 属性 | 值 |
|------|-----|
| 名称 | 保姆 |
| 图标 | 👶 |
| 色系 | 紫色渐变 `.jz-cat.nanny`（`#9a6bd1 → #4d2a78`） |
| 目标用户 | 有育儿/养老需求的家庭租客、双职工家庭 |

**特点：** 长周期服务为主（按月/按次），下单流程含面试匹配环节，支付支持月付套餐。

## 3. 页面设计

### 3.1 列表页 `juzhu-jiazheng-list.html?type=nanny`

- Tab：全部 / 育儿 / 养老 / 钟点 / 月嫂
- 卡片差异化：
  - 长周期：月价大字 + 「持证 · 3年+经验」标签
  - 钟点：次价 + 可约时段
- 营销位复用：`jz-promo-card.deep` 企业月付套餐

### 3.2 详情页 `juzhu-jiazheng-detail.html?sku=nanny-hourly-3h`

**长周期服务（住家/育儿/月嫂/养老）：**

| 区块 | 内容 |
|------|------|
| 服务者画像 | 头像、姓名、等级 L3+、证书、好评率 |
| 服务范围 | 做饭/保洁/育儿/陪护等清单 |
| 价格方案 | 26天/月/季度，企业月付折扣 |
| 需求表单 | 家庭人数、房屋面积、特殊需求（过敏/宠物） |
| 匹配方式 | 「平台推荐」/ 「指定面试」 |
| CTA | 「提交需求 · 等待匹配」 |

**短周期（钟点工/医院陪护）：**

- 与保洁类似：选时间 → 立即预约 → 支付

### 3.3 匹配与面试（保姆专属状态）

在通用状态机前增加：

```
submitted → matching → interviewed → confirmed → pending(进入派单)
  已提交     匹配中      已面试        已确认        待派单
```

原型简化：提交后直接进入 `pending`，详情页展示「匹配中，客服 2h 内联系」。

### 3.4 支付

| 类型 | 支付模式 | 页面 |
|------|----------|------|
| 钟点工 | 单次全额预付 | `lvju-app-pay.html` |
| 住家/育儿 | 首月 50% 定金 + 月付 | `payment.html` 月付模式 |
| 月嫂 | 合同全款或分期 | `contracts.html` 关联 |
| 企业月付 | 对公转账 | `p-transaction.html` T+5 结算 |

## 4. 业务流程

**钟点工（短周期）：**
```
选SKU → 预约时间 → 支付 → 派单 → 上门 → 完工 → 评价
```

**住家/育儿（长周期）：**
```
提交需求 → 平台匹配3名候选人 → 线下面试/视频面试
  → 确认人选 → 签合同 → 付定金 → 上岗 → 月度评价
```

## 8. 中台认证（重点）

保姆品类认证要求最严：

| 子类 | 证书 | 背调 | 页面 |
|------|------|------|------|
| 育儿嫂 | 育婴师证 + 健康证 | 无犯罪记录 | `p-onboarding-review` |
| 月嫂 | 母婴护理专项 | 同上 | `p-cert-issue` |
| 养老护理 | 养老护理员证 | 同上 | `g-whitelist-service` |
| 钟点工 | 家政 L1+ | 基础背调 | `s-cert.html` |

**六步入驻全流程**见 `PRD-家政-00-全流程与中台认证.md`。

未通过背调不可匹配（R-104）。

## 9. 评价

**钟点工：** 单次评价，同保洁流程。

**长周期：** 月度评价 + 合同到期总评

评价维度：

- 专业技能 / 责任心 / 沟通能力 / 卫生习惯
- 长周期支持「更换服务者」申诉入口

回流：`p-service-review.html` → `p-credit-engine.html`
