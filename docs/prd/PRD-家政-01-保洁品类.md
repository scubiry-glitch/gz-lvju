## 3. 页面设计

### 3.1 列表页 `juzhu-jiazheng-list.html?type=cleaning`

**布局**（沿用 v3-grid 风格 + `lvju-app.css`）：

- 顶栏：返回 + 「保洁服务」+ 筛选
- 筛选条：全部 / 日常 / 深度 / 开荒 / 擦玻璃 / 油烟机
- 列表卡片：
  - 左：封面图或渐变色块
  - 中：服务名 + 规格标签 + 销量/好评
  - 右：起价（金色 `--gold-deep`）+ 「预约 ›」

**字段展示：**

- `name` 服务名
- `spec` 规格说明
- `price_from` + `price_unit`
- `tags` 如「新用户立减」「金牌服务者」

### 3.2 详情页 `juzhu-jiazheng-detail.html?sku=deep-clean-4h`

**区块：**

1. **头图轮播** — SKU 封面 + 服务场景
2. **价格区** — 起价 + 券后价（如有 `promo_price`）
3. **服务说明** — 包含项目清单（厨卫/地面/玻璃…）
4. **服务者标准** — L3+ 持证、已投保、好评率 ≥4.8（链 `s-cert.html`）
5. **预约表单**
   - 服务地址（默认关联当前房源 `units` 地址，可改）
   - 联系电话（脱敏展示）
   - 上门时间（日期 + 时段）
   - 备注（textarea）
   - 照片上传（可选，参照 `repair.html`）
6. **底部 CTA** — 「立即预约 ¥268」→ 创建订单

### 3.3 支付页

复用 `lvju-app-pay.html`：

- 订单摘要：深度清洁 · 4小时 · 东博公寓
- 步骤条：预定下单 ✓ → **支付** → 完成
- 支付方式：贝壳支付（默认）/ 微信 / 银行 APP
- 存管说明：服务完成确认后结算

### 3.4 进度与评价

- 进度：`repair.html` Tab「我的报修」复用为「我的服务」
- 评价：`lvju-app-review.html` 分项：
  - 清洁效果 / 准时程度 / 服务态度 / 性价比

## 4. 业务流程（保洁专属）

```
选SKU → 填预约信息 → 支付 → 入工单池(type=保洁)
  → 中台按距离+等级派单 → 保洁员接单
  → 上门清洁(serving) → 完工拍照(done)
  → 客户验收评价(rated) → 信用回流
```

**保洁特殊规则：**

| 规则 | 说明 |
|------|------|
| 时段限制 | 8:00–20:00 可预约，开荒可协商 |
| 人数配置 | 深度/开荒按面积自动推荐人数 |
| 耗材 | 标准耗材含在价内，特殊药剂另计（下单时勾选） |
| 取消政策 | 服务前 2h 免费取消；2h 内扣 30% |
