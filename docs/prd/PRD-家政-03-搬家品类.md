## 3. 页面设计

### 3.1 列表页 `juzhu-jiazheng-list.html?type=moving`

- 顶部计算器入口：「估算搬家费用」
- 车型筛选：面包车 / 金杯 / 厢货 / 纯人力
- 卡片：车型图 + 师傅人数 + 起价 + 「预约 ›」

### 3.2 详情页 `juzhu-jiazheng-detail.html?sku=resident-move`

**核心表单（搬家专属字段）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 搬出地址 | 地址选择 + 楼层/电梯 | ✓ | 可关联当前 `unit` |
| 搬入地址 | 地址选择 + 楼层/电梯 | ✓ | |
| 搬家日期 | 日期 | ✓ | 提前 1 天预约 |
| 时段 | 上午/下午 | ✓ | |
| 车型 | 单选 | ✓ | 金杯/厢货/… |
| 大件物品 | 多选 | | 冰箱/洗衣机/钢琴/… |
| 打包服务 | 开关 | | 日式搬家含 |
| 联系电话 | input | ✓ | |
| 备注 | textarea | | |

**费用预览区：**

- 基础车费 + 楼层费 + 大件加价 + 打包费 = 预估总价
- 金色大字展示，底部 CTA「预约搬家」

### 3.3 支付

- 预约金：总价 30% 预付（`lvju-app-pay.html`）
- 尾款：搬家完成现场确认后支付（原型可跳转二次支付页）
- 存管：尾款结算前资金冻结

### 3.4 进度

- 状态细分：`accepted` 后增加 `loading`（装车中）→ `transit`（运输中）→ `unloading`（卸车中）
- 原型简化为 `serving` 统一「服务中」，详情页展示子状态文案

## 4. 业务流程

```
选车型/填地址 → 费用估算 → 付预约金 → 派单(搬家团队)
  → 师傅接单 → 上门装车 → 运输 → 卸车就位 → 现场确认 → 付尾款 → 评价
```

**搬家特殊规则：**

| 规则 | 说明 |
|------|------|
| 提前量 | 至少提前 24h 预约；周末加价 10% |
| 楼层费 | 无电梯每层 +¥30/件 |
| 钢琴/保险 | 须 L4+ 团队 + 货运险（`p-insurance.html`） |
| 取消 | 前 24h 免费；24h 内扣预约金 50% |
| 企业搬迁 | 需 B 端运营确认合同（`contracts.html`） |

---

## 5. 派单规则

- 团队派单（非单人）：`v-team.html` 绑定服务商旗下 2+ 服务者
- 匹配因子：车型资质、搬运保险、历史破损率
- 钢琴/企业类仅派 L4+ 认证团队

**B 端看板**（`b-dispatch-board.html`）：

- Kanban 列：待派 → 匹配中 → 已派 → 服务中 → 已完成
- 卡片展示：搬出/搬入地址、车型、团队负责人
