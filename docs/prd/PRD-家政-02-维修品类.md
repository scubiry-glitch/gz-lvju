## 3. 页面设计

### 3.1 列表页 `juzhu-jiazheng-list.html?type=repair`

- 顶栏 + 紧急报修入口（红色角标「30分钟响应」）
- 分类 Tab：家电 / 管道 / 灯具 / 门窗 / 防水 / 空调
- 卡片展示：故障类型图标 + 起价 + 响应承诺

### 3.2 详情页 / 报修页

**两种入口合并：**

1. **标品预约** — 空调清洗等固定 SKU → `juzhu-jiazheng-detail.html`
2. **故障报修** — 非标准故障 → 直接进入 `repair.html` 报修 Tab

**报修表单字段**（已有 `repair.html`）：

| 字段 | 类型 | 必填 |
|------|------|------|
| 故障类别 | 单选 grid（水电/门窗/家电/其他） | ✓ |
| 问题描述 | textarea | ✓ |
| 房源地址 | 下拉关联 `units` | ✓ |
| 联系电话 | input | ✓ |
| 期望时间 | 日期 + 时段 | |
| 现场照片 | 上传 1–3 张 | 建议 |

提交调用：`BZF_ORDERS.create({ type: '报修', category: 'repair', ... })`

### 3.3 进度 Tab（`repair.html`）

- 工单列表：状态徽章 + 进度条（15%→100%）
- 详情展开：服务者信息（姓名/等级/电话）
- 待评价入口 → `lvju-app-review.html`

### 3.4 支付

- **标品**（空调清洗等）：下单后立即支付
- **报修类**：上门检测后确认报价 → 二次支付（原型可简化为预付 ¥99 检测费，多退少补）

复用 `lvju-app-pay.html`，订单号关联 `WO-2026-xxxxx`。

## 4. 业务流程

```
路径A（标品）: 选SKU → 预约 → 支付 → 派单 → 上门 → 完工 → 评价
路径B（报修）: 填故障单 → 预付检测费 → 派单 → 上门检测 → 确认报价 → 补差价 → 维修 → 完工 → 评价
```

**维修特殊规则：**

| 规则 | 说明 |
|------|------|
| 紧急单 | 管道堵塞/漏水标记高优先级（`p-service-demand` b-hi） |
| 配件费 | 检测后生成配件清单，用户确认后支付 |
| 质保 | 维修项 30 天质保，质保内同故障免费上门 |
| 拒单 | 超技能范围服务者可拒单，回工单池重派 |

## 5. 派单规则

来源：`p-service-demand.html` 示例工单

| 工单类型 | 优先级 | 派单策略 |
|----------|--------|----------|
| 管道疏通 | 高 | 30 分钟内响应，3km 优先 |
| 家电维修 | 中 | 按工种证书匹配 |
| 灯具安装 | 低 | 可合并派单 |

**工种证书匹配：**

- 电工证 → 灯具/线路
- 制冷工证 → 空调
- 管道工证 → 疏通/防水
