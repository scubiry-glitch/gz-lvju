## 3. 订单与权益（线上实况）

- 演示订单 **2 笔**（既有幂等关联主站 `gr_orders`），卡券 **6 张**；全部 `paid_minor=0`，无资金流水。
- 兑换码 **4 张，全部已停用**（均为本轮线上验证所发，验证后即停用，未兑换、无遗留活码）；线上兑换记录为空属预期，能力由隔离库验收覆盖。
- 新增演示数据走购买/兑换流程即可产生，无需手工建单。

## 4. 账号与权限

- 页面级演示账号见仓库页 `screens/demo-accounts.html`（口令只在库与该页，不在文档复制）；commerce 权限默认不授予旧业务角色，按 M1-A 角色表配置：平台配置与履约（`commerce.admin.read/write`）、独立复核（`+commerce.admin.review`）、商户资料与售后协同（`commerce.merchant.*`）、门店核销（`commerce.merchant.read/redeem` + 门店核销人员授权）、个人用户（本人资产）。
- 交叉验收所用的「2 客户 + 3 商户核销员」为隔离库临时账号，不落线上。

## 5. 维护

- 补缺：`node scripts/commerce/seed-guiyang-demo.cjs --apply`（幂等，仅创建缺失项，保留已编辑记录与库存）；`node scripts/commerce/link-main-systems.cjs`（幂等补齐历史主站关联）。
- 演示识别：商品名带「（演示）」后缀，`initialization.batch=guiyang-life-demo-v1`；真实交易与真实商家资料不得混入该批次。
- 兑换码发放/停用记录在「操作审计」与 `commerce_audit` 可查，明文码不入库。
