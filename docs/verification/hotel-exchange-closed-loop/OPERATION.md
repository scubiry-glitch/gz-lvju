# 酒店通兑与三品类 · 操作说明

适用范围：sytest 预览域名的无资金演示环境。所有购买/预约/核销均为零资金演示，页面与接口均有标识。

## 1. 入口

| 端 | 入口 | 说明 |
|---|---|---|
| C 端 · 名录 | `/juzhu-hotels.html?city=贵阳` | 6 档酒店名录（80/100/120/160/180/200 元档），品牌/关键词筛选，公开可看 |
| C 端 · 选券 | `/juzhu-vouchers.html?kind=skus&category=hotel_exchange` | 同类直达：`scenic_ticket` 门票 / `dining` 餐饮 / `online_service` 线上权益 |
| C 端 · 首页 | `index.html` 领券中心 | 「酒店通兑券 / 景点门票券 / 本地餐饮券」三张卡 |
| 商户中心 | `/screens/commerce-merchant.html` | 门店管理（商家自建门店）、核销人员、核销记录 |
| 运营中心 | `/screens/commerce-admin-skus.html` | 券商品创建：核销方式（线上/线下）、通兑档位、门店联动 |

## 2. 三类券的使用方式（C 端）

| 券类型 | 领取后 | 使用 |
|---|---|---|
| **酒店通兑券**（线下 · 档内任选） | 我的卡券 →「选酒店预约」 | 弹窗内选**档内任一酒店**+入住日期 → 提交（占用该店当日名额）→ 入住当日出示动态码；可换店改期/取消（自动释放旧名额） |
| **门票 / 餐饮**（线下 · 绑定门店） | 「预约服务」选日期 | 到绑定门店当日出示动态码（既有链路） |
| **线上权益**（线上 · 免预约） | 「出示核销码」 | 无需预约，直接出示动态码，商户线上确认 |

## 3. 商户侧点亮酒店核销（一次性配置）

酒店通兑券发在「筑城酒店通兑运营台（演示）」名下，但**核销人是所选酒店所属事业群商户的员工**：

1. 账号中心建/选一个个人账号，绑定对应事业群商家（`jz_vendors`：柏曼/城市便捷/宜尚/怡程/中寓事业群（酒店通兑试点演示））；
2. 商户中心 →「核销人员」→ 新增：选事业群商户 + 目标酒店门店 + 该账号 → 提交复核发布；
3. 该账号在商户中心「核销记录」即可对预约了该酒店的通兑券做 preview + 核销；**未授权门店的员工核销会被 403 拒绝**，核销记录归集到所选酒店的事业群商户（结算账单按事业群分别出账）。

## 4. 商家自建门店（线上/线下券的门店来源）

商户中心 →「门店管理」→ 新增：门店类型选「线下门店」（预约到店）或「线上服务台」（线上核销通道，虚拟门店）。创建券商品时：
- 核销方式=**线下到店** → 门店下拉只列本商户线下门店（选通兑档位时只列该档锚点）；
- 核销方式=**线上核销** → 门店下拉只列本商户「线上服务台」。

## 5. 运维命令

```bash
systemctl restart sy-commerce-preview.service        # 38780，启动自动迁移
node scripts/commerce/seed-hotel-exchange-demo.cjs --apply   # 幂等补缺
node scripts/commerce/seed-hotel-exchange-demo.cjs --apply --clean  # 有业务单据时拒删
node scripts/commerce/live-hotel-check.cjs           # 线上 19 项验收（可重复跑）
curl -H 'Host: sytest.meizu.life' http://127.0.0.1:38780/api/commerce/v1/hotels
```
